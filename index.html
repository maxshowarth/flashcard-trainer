Tips & tricks — how to win

The cards are already vivid pictures — that's your biggest advantage. Don't recode them into letters or short codes: that throws the advantage away and forces a double translation (icon → code while watching, then code → icon while showing). Arbitrary letter strings are exactly what memory is worst at. Work with the images directly.

Link the images into a story

Chain each card to the next with a vivid, exaggerated, cause-and-effect scene. For ⛵ 🪣 🐴: "a sailboat capsizes into a giant bucket, and a horse drinks it dry." Replay the story forward at recall and the order comes out on its own.

  • Order is baked in. A causal chain enforces the sequence, which is the hard part of the game.
  • Repeats are easy. "The horse shows up again, now kicking a door" handles a second 🐴 cleanly, where a letter string just gives you two identical letters you'll transpose.
  • Say the name as you picture it. Image + word together sticks far better than either alone.

Scale the technique to the length

  • 3–5 cards: skip the story. Just repeat the names in a tight loop ("boat-bucket-horse"). Fast and enough.
  • 6–10 cards: use the linking story above.
  • 10+ cards: use a memory palace — walk a familiar route (front door, couch, fridge…) and drop one card at each spot. This scales essentially without limit.

In the moment

  • Watch actively. Start building the story on card 1 — don't passively watch and reconstruct later.
  • Chunk in 3s. One scene per ~3 cards.
  • Trust the replay. On the beat, read the story off in order — don't hunt the grid.
  • Study the pool. The cards in play are fixed for the whole game (shown above the board), so get familiar with the set before you start.
